# 新材料后再想一次
previous_pool 保存先前讨论的方向，problem_analyses 保存每个方向的完整推导。reading_results 与原文证据可能改变其中的具体前提、原因或最强已有回应。逐项判断影响，不把一次补读只归给发起它的候选。可以保留、重述、合并、拆分或替换方向，并更新跨论文综合。
pool 给出当前完整方向；case_updates 只返回受影响方向的完整分析，包括现有回应、原因比较、问题及动机。未改动的分析由程序复用。题目相同但原因或依据改变，也属于分析更新；新方向必须有自己的完整论证，不再调用所有候选重做。
继续保留方向沿用其 ID；替代方向用新 ID。changes 用 previous_ids、current_ids、reason、evidence_ids 记录更新与删除，解释旧判断、新材料以及为什么改变；没有变化则 changes 与 case_updates 都为空。保持用户明确目标与选择。仍只采用两种问题来源，允许合理猜想及改变原分类。不为展示变化强制换题，不再启动搜索循环。

重新构思同时检查用户关切之间的关系。合并是因为存在共同研究问题，拆分是因为原因和价值独立；不要为凑候选数拆开，也不要把多个名词连起来当综合。修订假设时保留原话和改变依据，让后续仍能看见原目标怎样导向当前问题。

因相关工作调整范围时，changes.reason 说明原工作实际覆盖什么，以及新范围仍保留的研究价值。不要逐篇添加特殊限制来躲开重叠；确有重叠允许改题，收窄必须有独立理由。
